# Prompt Templates

This directory contains prompt templates used by RepoDoc AI for generating documentation via Amazon Bedrock.

## Files

- `readme.md` — Prompt for generating README documentation
- `installation.md` — Prompt for generating installation instructions
- `architecture.md` — Prompt for generating architecture summaries
- `api.md` — Prompt for generating API documentation
- `folder_structure.md` — Prompt for generating folder structure documentation
- `tech_stack.md` — Prompt for generating tech stack documentation
- `portfolio.md` — Prompt for generating portfolio descriptions
- `templates.md` — Legacy combined prompt templates (kept for reference)
